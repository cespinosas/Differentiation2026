# Differentiation2026
Code for the analyses in the paper 'Gene regulatory networks and the organization of cell diﬀerentiation in multicellular organisms' by F. Meraz-Segura, A.Ch. Guerrero-Vaca, R. Alcaraz-Barrera and C. Espinosa-Soto.


Instituto de Fisica, UASLP.

## FromGRNstoCTTMs

This section contains code for sampling, exploration and analyses of small model GRNs and their Cell Type Transition Maps (CTTMs).

## ExpSustGRNs
Analyses of GRNs sustained on experimental evidence.
